# East Asia, Southeast Asia + Oceania 1993 Country List

## Purpose

This file defines the initial Version 0.1 country setup for East Asia, Southeast Asia, and Oceania in the 1993 start date. It follows the Europe + Former Soviet Union country-list template and captures sovereign states, disputed territories, colonial remnants, and major insurgent or de facto entities.

It should track:
- Country name
- Proposed EU5 tag
- Capital
- Government type
- Alignment / bloc
- 1993 status
- Notes for borders, conflicts, claims, and implementation

---

## Tag Rules

- Prefer recognizable three-letter tags.
- Avoid conflicts with existing EU-style tags where possible.
- Use placeholder tags until EU5 tag constraints are known.
- Disputed islands, colonial territories, and autonomous regions may be represented as special provinces, subjects, or modifiers unless full tags are needed.
- Insurgencies and de facto administrations may receive tags later if gameplay needs justify them.

# East Asia, Southeast Asia + Oceania 1993 Country List

## Purpose

This file defines the initial Version 0.1 country setup for East Asia, Southeast Asia, and Oceania in the 1993 start date. It follows the Europe + Former Soviet Union country-list template and captures sovereign states, disputed territories, colonial remnants, autonomous regions, and major insurgent or de facto entities.

It is intended to be implementation-ready enough to support later work on:
- Country history setup
- Province ownership and control
- Subject relationships
- Cores, claims, and disputed regions
- Rebel and insurgency content
- Starting diplomacy and alignments
- Regional event chains
- Future independence, handover, and civil-war paths

This file should track:
- Country name
- Proposed EU5 tag
- Capital or command center
- Government type
- Alignment / bloc
- 1993 status
- Implementation role
- Notes for borders, conflicts, claims, and implementation

---

## Tag Rules

- Prefer recognizable three-letter tags.
- Avoid conflicts with existing EU-style tags where possible.
- Use placeholder tags until EU5 tag constraints are known.
- Avoid hyphenated tags unless absolutely necessary; use them only as temporary documentation placeholders.
- Disputed islands, colonial territories, autonomous regions, and micro-dependencies may be represented as special provinces, subjects, province modifiers, estate-like autonomy systems, or disaster/revolt mechanics unless full tags are needed.
- Insurgencies and de facto administrations may receive tags later if gameplay needs justify them.
- Rebel tags should only become playable or map-owning tags if they control meaningful territory or are required for a major conflict system.
- Colonial and associated territories should be reviewed once EU5 subject mechanics are known.

### Tag Status Legend

| Status | Meaning |
|---|---|
| Required | Should exist as a normal country tag in V0.1. |
| Recommended | Strong candidate for a tag, subject, or scripted entity. |
| Conditional | Add as a tag only if the map scale, conflict system, or subject mechanics justify it. |
| Modifier only | Best represented through province modifiers, cores, claims, unrest, decisions, or events. |
| Map-only | Should appear geographically but probably does not need a normal country tag. |

---

## Implementation Rules

- All UN member sovereign states in the region in 1993 should be represented as normal country tags unless map scale makes them impossible.
- Palau should be represented as a transitional entity because it becomes independent in 1994.
- Hong Kong is represented as a standard EU5 Vassal of the United Kingdom using `HKG`; Macau is represented as a standard EU5 Vassal of Portugal using `MAC`. Their 1997 and 1999 handovers are major regional scripted paths.
- East Timor is internal Indonesian occupied/disputed regional content, with Fretilin represented as internal resistance content and a later independence path.
- Major insurgencies should be represented through unrest, province control, rebel factions, modifiers, or disaster mechanics before being promoted to full tags.
- Very small Pacific territories may be map-only unless they have strategic, colonial, military, or event-chain value.
- Maritime disputes should not automatically become full country tags; they should usually be claims, province modifiers, sea-zone modifiers, or special province ownership states.
- Capitals listed for rebel groups are command centers or likely headquarters, not always formal capitals.
- Alignment is a gameplay abstraction for 1993 diplomacy, not a strict ideology label.

## Design Notes

- This region needs more than simple sovereign-state coverage because 1993 Asia-Pacific gameplay depends heavily on dependent territories, handovers, unresolved civil wars, maritime disputes, and insurgencies.
- The minimum viable version should include all sovereign states, Hong Kong, Macau, internal East Timor occupation content, Palau, the Korean DMZ, the Taiwan Strait, and South China Sea disputes.
- Deeper versions should add Indonesian separatism, Bougainville, New Caledonia, and French nuclear-testing politics. Myanmar and consolidated Philippine content follow-up is centralized in `country_content_design_backlog.md`.
- For V0.1, avoid over-fragmenting China, Indonesia, Myanmar, and the Pacific unless the map and rebel systems can support it cleanly.
