# Latin America + Caribbean 1993 Country List

## Purpose

This file defines the initial Version 0.1 country setup for Latin America and the Caribbean in the 1993 start date. It follows the Europe + Former Soviet Union country-list template and captures sovereign states, dependencies, insurgencies, and disputed territories.

Mexico is intentionally treated as part of the North America regional setup for Version 0.1, but should be cross-referenced here for Latin American balance, trade, migration, and future 1994 Zapatista-event content.

It should track:
- Country name
- Proposed EU5 tag
- Capital
- Government type
- Alignment / bloc
- 1993 status
- Notes for borders, conflicts, claims, and implementation

---

## Tag Rules

- Prefer recognizable three-letter tags.
- Avoid conflicts with existing EU-style tags where possible.
- Tags should use three letters where possible and avoid hyphens.
- If a three-letter tag is unavailable, use a clear temporary placeholder and mark it for later engine validation.
- Use placeholder tags until EU5 tag constraints are known.
- Dependencies and overseas territories may be represented as owner provinces or special subjects unless gameplay needs justify tags.
- Insurgencies, indigenous movements, and disputed regions should be preserved for future mechanics.

## Implementation Notes

- Mexico is not duplicated as a full playable row here because the primary 1993 setup should live in the North America file.
- Sovereign Caribbean microstates remain country actors. Non-sovereign Caribbean dependencies are direct territories of their administering states.
- French, British, Dutch, and United States island dependencies are represented directly within their administering states and receive no separate starting actors, subjects, or technical tags unless an explicit locked exception exists.
- Guerrilla and insurgent rows are design placeholders for internal rebel, estate, disaster, or mission mechanics rather than guaranteed independent map tags. Shining Path and MRTA are consolidated into Peru (`PER`); content follow-up is centralized in `country_content_design_backlog.md`.
- Major event hooks for this region include NAFTA implementation in 1994, the Zapatista uprising in 1994, the 1994 Haiti intervention, the 1995 Cenepa War, the Guatemalan peace process, and the late-1990s evolution of Colombian conflict mechanics.
